# M4 — Claude CLI bridge, AI fallback, answer cache

**Spec:** `docs/superpowers/specs/2026-09-13-job-application-filler-design.md` §1.1, §3.4, §5
**Prerequisite:** M3 fill engine code-complete (jsdom green). Live ATS rows in
`docs/ats/findings.md` are **not** required for M4 — AI handles *unresolved*
custom questions, not platform selectors.

---

## Goal

When heuristics cannot match a field (`resolveAll` → `unresolved`), batch all
eligible descriptors into **one** server-side CLI call, validate with
`--json-schema`, fill answers above the 0.6 confidence threshold, and cache
repeat questions in `profile/answers.json`.

---

## Hard rules (inherited)

- Spawn `claude` with an **argv array** — never a shell string, never
  `shell: true`.
- **Never `claude --bare`** — forces `ANTHROPIC_API_KEY`.
- Kill the child after **60s** (spec §4.21).
- Wrap scraped job descriptions in `<job_description>` delimiters (spec §4.15).
- **Never auto-submit** — unchanged; AI only produces values for existing controls.
- Server binds `127.0.0.1`; every `/api/ai/*` request requires the pairing token.

**Files:**
- Create: `packages/server/src/storage/json-store.ts`
- Create: `packages/server/src/ai/cache.ts`

`answersPath(dataDir)` → `profile/answers.json`.

---

## Task 3: Claude CLI bridge

**Files:**
- Create: `packages/server/src/ai/claude-cli.ts`
- Create: `packages/server/src/ai/codex-cli.ts` (fallback only)
- Create: `packages/server/src/ai/prompts/map-fields.ts`

Verified invocation (spec §5):

```ts
spawn('claude', [
  '-p', prompt,
  '--system-prompt', systemPrompt,
  '--json-schema', JSON.stringify(schema),
  '--tools', '',
  '--no-session-persistence',
  '--output-format', 'json',
  '--model', 'sonnet',
])
```

Parse the JSON **array** output; take the last `type === 'result'` event;
prefer `.structured_output`.

Codex is used only when Claude returns auth or rate-limit errors.

## Task 4: Provider and HTTP route

**Files:**
- Create: `packages/server/src/ai/provider.ts`
- Create: `packages/server/src/routes/ai.ts`
- Modify: `packages/server/src/app.ts`

`POST /api/ai/map-fields`:
1. Validate body with `MapFieldsRequestSchema`
2. Serve cache hits immediately (`source: 'cache'`)
3. One CLI call for remaining fields
4. Persist new answers; return `{ answers, error? }`

## Task 5: Extension wiring

**Files:**
- Create: `packages/extension/src/lib/ai.ts`
- Create: `packages/extension/src/content/ai-fill.ts`
- Create: `packages/extension/src/content/job-description.ts`
- Create: `packages/extension/src/content/detect/signin-gate.ts`
- Modify: `packages/extension/src/content/index.ts`
- Modify: `packages/extension/src/background/service-worker.ts`

Fill pipeline after M4:

```
sync profile → harvest → resolve → apply heuristics
  → AI fallback (online + eligible kinds) → review panel
```

AI-eligible kinds: `text`, `textarea`, `select`, `radio`, `checkbox`, `date`.
Deferred to M5: `file`, `combobox`.

Workday sign-in gate (spec §4.12): if detected, return a single `needs-user`
row — do not attempt fill.
